# Settings and performance measuring

Settings (`src/settings.rs`): the `Settings` resource (VSync, fullscreen, camera zoom, UI scale, and the graphics options FPS limit, MSAA, color grading and shadows) is the only source of truth. It is loaded from `settings.ron` when the plugin is built (so the window opens in the right mode), applied to the primary window and the 2D camera (projection scale, `Msaa`, `Hdr` while color grading is on) whenever it changes, and saved then. The FPS limit is `settings::limit_frame_rate`, which sleeps in `Last` until the next frame is due; the shadows are a run condition (`light::shadows_on`) of the sun's shadow and turn it off in the light layer. The file lives next to the executable (`target/debug/` under `cargo run`). Escape toggles the `Menu` state (`settings::toggle_menu`) once no window of the HUD is left: `ui::sync_state` runs before it and closes the topmost one (the selection's popup, then the inventory), taking the key away; while it is `Open`, `Time<Virtual>` is paused, which stops physics and everything driven by game time. The HUD shows the menu and sends the whole changed `Settings` back as a `hud::Action`.

`src/perf.rs` measures the frame time and, with marker systems before and after Avian's sets, the wall time of the physics for the HUD. Wall time between marker systems includes waiting for unrelated systems with conflicting access, so it is no measure for single game systems; use `cargo tracy` for those.
